# Outputs

Generated outputs are intentionally ignored by Git.

Final accuracy-first videos are expected under a structure similar to:

```text
outputs/CoralGuard_X_ACCURACY_FIRST/06_Final_Videos/<video_name>/
├── <video_name>_ACCURACY_FIRST_FINAL.mp4
└── <video_name>_ACCURACY_FIRST_summary.json
```

A summary CSV may also be generated at:

```text
outputs/CoralGuard_X_ACCURACY_FIRST/06_Final_Videos/accuracy_first_video_summary.csv
```

Keep raw/generated outputs outside version control unless they are small, curated examples intended for documentation.
